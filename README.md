# Windows Server Lab

Laboratório prático de infraestrutura utilizando Windows Server e Windows Client,
simulando um ambiente corporativo.

## Objetivo

Construir e documentar uma infraestrutura Windows em ambiente virtualizado,
explorando conceitos de administração de servidores, Active Directory, DNS,
Group Policy, usuários, grupos, permissões e gerenciamento de rede.

## Ambiente

- VirtualBox
- Windows Server
- Windows Client
- Active Directory Domain Services
- DNS
- Group Policy
- Rede virtual isolada
